# Roadmap

## v1.0.0 — Testnet Launch (Q4 2026)

- [x] Core escrow contract (create, milestone submission, approval, cancellation)
- [x] On-chain reputation event emission
- [x] REST API with JWT authentication
- [x] Next.js dashboard with Freighter integration
- [x] PostgreSQL + Prisma data layer
- [ ] Dispute resolution contract
- [ ] Arbiter DAO for dispute adjudication
- [ ] Full testnet deployment
- [ ] SDK npm package (v0.1.0)

## v1.1.0 — Multi-token & Mobile (Q1 2027)

- [ ] Multi-token escrow support (USDC, XLM, AQUA)
- [ ] React Native mobile app (iOS + Android)
- [ ] Offline escrow viewing on mobile
- [ ] Push notifications for milestone events
- [ ] Webhook delivery with retry logic

## v2.0.0 — Mainnet & Audit (Q2 2027)

- [ ] Independent Soroban contract security audit
- [ ] Mainnet deployment
- [ ] Reputation score portability (export to other Stellar dApps)
- [ ] Multi-language support (EN, FR, SW, PT)
- [ ] Fiat on-ramp integration for African markets
- [ ] Enterprise escrow templates (fixed-price, time-and-materials, retainer)

## Long-term Vision

- Cross-chain escrow via Stellar bridge protocols
- Decentralised arbiter marketplace
- AI-assisted milestone scoping and pricing
- Integration with African fintech rails (M-Pesa, Flutterwave)
